# 관심종목 1·2·3그룹 규칙과 근거

`scripts/watchlist.mjs check` 가 쓰는 규칙의 출처다. 채택한 값은 `scripts/watchlist/classify.mjs` 의
`RULES` 에만 있고, 이 문서는 그 값이 어디서 왔는지(어떤 구간을 시험했고 결과가 어땠는지)를 적는다.
값을 바꾸려면 아래 시험을 다시 돌려 이 문서와 `RULES` 를 함께 고친다.

## 1. 데이터와 방법

- **종목**: 코스피·코스닥 보통주 2,487개(우선주·ETF·스팩 제외, 상장 260거래일 이상). 2026-10-07 상장
  종목 기준이라 그 사이 상장폐지된 종목은 빠져 있다(생존 편향).
- **가격**: KIS 수정주가 일봉 2024-01 ~ 2026-10-07. 지수는 KIS 업종 0001(코스피)·1001(코스닥).
- **거래 시뮬레이션** (피봇 돌파, 2025-02 ~ 2026-10, 약 1.2만 건):
  - 셋업은 t일 종가까지의 정보로만 판단한다. 피봇은 t−3일까지 확정된 프랙탈 고점이다.
  - t+1일 고가가 피봇 이상이면 max(시가, 피봇)에 매수한다. 시가가 피봇 +5%를 넘으면 사지 않는다.
  - 손절 −8%, 익절 +24%(3R), 최대 60거래일 보유. 같은 날 손절가와 익절가를 모두 건드리면 손절로 친다.
  - 왕복 비용 0.3%. 한 종목은 청산 전까지 다시 사지 않는다.
- 결과는 **평균 R**(손절폭 대비 손익)로 비교한다. 1:3 손익비라 손익분기 승률은 약 26%다.
- **기준선**: 유동성(20일 평균 거래대금 ≥ 10억)만 통과한 모든 피봇 돌파. 7,860건, 승률 30.6%, +0.14R.
  기간 자체가 강세장이었기 때문에 기준선도 플러스다. 규칙은 기준선보다 나은지로 판단한다.

## 2. 그룹 정의

그룹은 겹칠 수 있다.

| 그룹 | 그 자리 돌파의 성과 (매수 스톱) |
|---|---|
| 1 강세선두 | 1,269건, 승률 28.1%, **+0.06R** — 우위 없음 |
| 2 추세시작 | 1,243건, 승률 30.5%, +0.14R — 기준선과 같음 |
| 2 중 수축 완료 | 246건, 승률 37.8%, +0.36R |
| 3 돌파대기 | §3 |

- **공통 — 거래대금**: 20일 평균 10억 미만은 백테스트에서 제외했다. 얇은 종목은 손절이 계획대로 체결되지 않는다.
- **1그룹**: 강도 상위(백분위 RS ≥ 90 ≈ 지수 대비 ≥ 1.32, §4)이면서 52주 고점 −20% 이내이고, 10일 고저폭 15% 초과나
  50일선 이격 25% 초과로 과열된 종목이다. 이 자리의 돌파는 기준선보다도 못해서 **사지 않는다**.
  ATR 8% 초과(−0.03R), 10일 고저폭 20% 초과(0.00R)도 같은 방향을 가리킨다.
- **2그룹**: 트렌드 템플릿(현재가 > 50일 > 150일 > 200일선, 200일선 20일 전보다 상승, 52주 저점 +25% 이상, 고점 −25% 이내)과
  52주 저점 대비 +30~150%(Stage 2 초입)를 만족하는 종목이다. 이 그룹은 그 자체로는 우위가 없으니 §5 점수로 3그룹 후보를 고른다.

## 3. 3그룹(돌파대기) — 알림 대상

조건: 수축 3회 이상, 마지막 수축 10% 이하, 10일 고저폭 12% 이하, 52주 고점 −20% 이내, 지수 대비 1~1.32(§4),
거래대금 10억 이상. 알림은 종가가 피봇 아래 8% 안에 있을 때만 낸다(백테스트 셋업과 같은 조건).

- 피봇: 좌우 3봉보다 높은 고가 중 가장 최근 것. "최근 N일 최고가"는 쓰지 않는다.
- 마지막 수축: 피봇 다음 봉부터 최저가까지 하락률. 피봇 봉의 저가는 넣지 않는다.

## 4. 지수 대비 강도 (RS 대신)

- RS 백분위는 전 종목 중 순위다(RS(1M) = 21거래일 수익률 백분위). 그대로 쓰려면 전 종목 가격이 필요하다.
- 대신 **종목 가중수익률 ÷ 자기 시장 지수 가중수익률**을 쓴다. 가중수익률 = 2×(63일) + 126일 + 189일 + 250일 수익 배수.
  백분위는 이 값의 순위일 뿐이므로 `> 1` 은 원고의 "종목 RS > 지수 RS" 와 정확히 같은 비교다.
- 같은 3그룹 조건(§3의 강도 외 조건)에서 강도 조건만 바꿔 비교:

| 강도 조건 | 건수 | 승률 | 평균 R |
|---|---|---|---|
| 백분위 RS 60~90 | 273 | 44.0% | +0.60 |
| **지수 대비 1~1.32** | 143 | 49.7% | **+0.79** |
| 지수 대비 1~1.5 | 157 | 48.4% | +0.75 |
| 지수 대비 > 1, 상한 없음 | 175 | 46.3% | +0.68 |

- 10일 고저폭 조건을 뺀 3그룹에서는 종목 RS ≤ 지수 RS 285건 +0.30R, 종목 RS > 지수 RS 244건 +0.66R로 갈렸다.

- 상한 1.32는 기간 중 "백분위 RS 90에 해당하는 지수 대비 값"의 중앙값이다. 백분위 RS ≥ 90은 모든 조합에서
  성과가 무너졌다(+0.04~+0.25R). 그래서 3그룹에 상한을 둔다.
- 원고는 "지수 RS는 보통 60~65"라고 가정했지만, 2026년 코스피 자신의 RS 백분위는 86~96, 코스닥은 39~82였다.
  고정값을 쓰지 말고 매번 지수를 계산한다. 지수가 강한 시기에는 통과 종목이 급감해(26Q2 3건, 26Q3 0건) 장세 필터처럼 작동한다.
- 지수 대비 값으로 백분위 판정을 대신했을 때의 일치율: RS ≥ 90 97%(재현율 84%), RS ≥ 75 89%(재현율 82%).
- 지수 대비 21일 초과수익 ≤ 5.5%p 는 백분위 RS(1M) ≤ 80 과 91% 일치한다(§5에서 사용).
- 사례 (2026-10-06 종가): KT&G 0.81, 메리츠금융지주 0.85, iM금융지주 0.85, DB손해보험 0.92는 수축 모양이 좋지만
  코스피보다 약해 알림에서 빠진다. 롯데렌탈 1.21, 현대해상 1.06은 알림이 된다.

## 5. 2그룹 점수 — 3그룹 후보 고르기

2그룹 종목을 20거래일마다 한 번씩 관측(2,801건)하고, 90일 안에 3그룹 돌파를 만들어 수익으로 끝났는지 봤다.
평균 성공률은 5.9%다.

| 조건 (2그룹 시점) | 충족 시 성공률 2025 / 2026 | 미충족 2025 / 2026 |
|---|---|---|
| 10일 고저폭 ≤ 12% | 14.9 / 4.3 | 4.6 / 1.7 |
| ATR14 ≤ 4.5% | 12.0 / 5.2 | 4.2 / 1.4 |
| 60일 깊이 ≤ 30% | 10.5 / 4.5 | 6.1 / 1.4 |
| 50일선 이격 ≤ 10% | 11.3 / 2.5 | 4.9 / 1.7 |
| 21일 강도 낮음 (RS(1M) ≤ 80) | 12.4 / 2.7 | 4.8 / 1.5 |
| 52주 저점 대비 ≤ 100% | 9.4 / 2.2 | 4.0 / 1.7 |

- **최근 한 달 덜 오른(쉬는) 2그룹이 더 잘 된다.** 한 달 새 급등한 종목은 베이스를 만들 준비가 안 됐다.

## 6. 주문

- 알림: 피봇 −3%. **알림가는 매수가가 아니다.** 피봇 −3%에서 미리 산 경우의 27%는 피봇에 닿지 못하고 전부 −1R로 끝났다.
- 매수: 피봇에 매수 스톱. 3그룹에서 진입 방식별 성과(백분위 RS 기준 조건):

| 진입 | 평균 R |
|---|---|
| 피봇 매수 스톱, −8% 손절 | +0.62 |
| 피봇 −3% 선매수 | +0.58 |
| 피봇 매수 스톱, 수축 저점 손절(최대 −8%) | +0.56 |
| 종가가 피봇 위일 때 종가 매수 | +0.53 |
| 위 + 돌파일 거래량 50일 평균의 1.5배 이상 | +0.64 |

- 추격 한도: 피봇 +5%(시뮬레이션에서 시가가 이를 넘으면 사지 않았다).
- 손절 −8%, 3R(+24%)에서 절반 익절. 익절 목표만 바꿔 보면 2R +0.41, 3R +0.62, 5R +0.92, 60일 보유 +1.52R로
  넓을수록 좋았지만 강세장 효과가 크다. 절반은 3R에서 확정하고 나머지는 길게 가져간다.
- 매수 당일 확인: 같은 업종에서 +3% 이상 오른 종목 비율이 10% 이하인 날의 돌파는 −0.02R, 35% 초과는 +0.45R(유동성 통과 전체).
  돌파일 거래량 1.5배 이상이면 3그룹 성과가 +0.62 → +0.74R. 둘 다 장중에만 알 수 있어 스크립트가 아니라 사람이 확인한다.
- 가격은 한국거래소 호가 단위로 내림한다.

## 7. 하지 않는 것

- **장세 필터**: 지수 60일선, 지수 20일선 > 60일선, 최근 20·40일 돌파 성적 모두 3그룹 성과를 개선하지 못했다.
  최근 돌파 성적은 오히려 반대로 움직였다(나쁜 시기 직후의 돌파가 더 좋았다). 하락 방어는 −8% 손절이 맡는다.
- **수축 저점 손절**: 고정 −8%보다 못했다(§6).

## 8. 한계

- 2025-02 ~ 2026-10은 코스피가 두 배 가까이 오른 강세장 위주다. 2026Q3 폭락기에는 3그룹형도 전패했다.
- 생존 편향(상장폐지 종목 없음). 3그룹 규칙은 143건으로 표본이 작다.
- 업종 동반 상승은 당일 종가 기준으로 계산해 장중 판단보다 약간 유리하게 나왔다.
- 시가총액은 쓰지 않는다.

## 9. 재현

백테스트는 Python(pandas)으로 cluefin 저장소의 KIS 클라이언트를 직접 써서 돌렸다. 스크립트는 이 저장소에 없다
(factory 의 `scripts/` 는 Node 만 둔다). 작성자 로컬의 `docs/plans/watchlist-groups-research/`(git 무시)에 있고,
순서는 `fetch_all.py` → `panel.py` → `run_bt.py <tag> stop 0 pct` → `ana.py`·`rules.py`·`regime.py` 다.
JS 포트가 같은 값을 내는지는 `tests/watchlist-features.test.mjs` 가 실제 종목 일봉으로 소수 6자리까지 확인한다.
