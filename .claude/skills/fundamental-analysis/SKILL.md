# Fundamental Analysis

다음 항목을 분석한다.

- 매출 성장률
- 영업이익률
- 순이익률
- ROE, ROA
- 부채비율
- 영업현금흐름
- PER, PBR, PSR
- 업종 평균 대비 위치

데이터 기준:
- **최신 실적은 DART**, 과거 추세와 비율은 KIS다. 조회 명령과 그 이유는
  `.claude/agents/market-review.md`의 재무 항목에 있다.
- 출처를 `dart-<보고서코드>`(11011 사업 / 11012 반기 / 11013 1Q / 11014 3Q) 또는
  `kis-annual`로 출력에 명시하고, 사용한 기간 목록을 함께 적는다.
- 두 출처를 함께 썼다면 어느 수치가 어느 출처인지 표에 적는다. 섞인 채로 성장률을
  계산하면 기준이 다른 값을 빼게 된다.
- KIS 비율(ROE·부채비율 등)은 최신 실적보다 뒤처진 기간의 값일 수 있으므로 그 기준
  기간을 함께 쓴다.

출력은 다음 순서로 정리한다.
- 재무 데이터 기준
- 사용 기간
- 긍정 요인
- 부정 요인
- 확인 필요 데이터

추정하지 말고 데이터가 없으면 없다고 표시한다.
